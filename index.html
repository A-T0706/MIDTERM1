Reimagining Harlem Plaza
as a stronger public space

This project studies the current plaza and presents an AI-assisted redesign proposal. The redesign focuses on adding more greenery, decorative planting, gathering spaces, comfort, and a stronger visual identity for the community.

🌿

More Greenery

Additional planting beds, layered flowers, and more landscape elements make the plaza feel more alive.

✨

Decorative Features

New decorative lighting and design elements improve visual appeal.

🪑

Social Seating

More seating encourages gathering and everyday use.

🌞

Comfort + Shade

Trees and shade improve usability and comfort.

Current Conditions

The plaza has a strong base but lacks decorative richness and visual interest.
